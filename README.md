# Ragdoll
ampliar informacion Stick Fight: The Game es un juego de lucha alocado, centrado en el combate de figuras de palo. Los puntos fuertes de este juego son el caos, la cantidad de armas, la edición de niveles y la alta interacción con dichos niveles. Es sencillo, adictivo y perfecto para combatir contra amigos tuyos, sea online o en multijugador local.
